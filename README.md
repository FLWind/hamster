# HAMSTER.SKIN 🐹

Шуточный сайт про биржевых хомяков: иллюстрации, типажи трейдеров, жизненный цикл сделки и интерактивный тест «Какой ты биржевой хомяк?».

Статический проект на **HTML + CSS + JavaScript**, без фреймворков, API, сборки и сторонних зависимостей. Данные теста хранятся только на открытой странице, никуда не отправляются.

## Локальный запуск

Откройте `index.html` в браузере либо запустите сервер из корня проекта:

```bash
python3 -m http.server 8000
```

Сайт будет доступен по адресу `http://localhost:8000/`.

## Размещение на собственном VPS с Nginx

Для сайта нужен только веб-корень с содержимым репозитория. Например:

```bash
sudo mkdir -p /var/www/hamster.skin/public
sudo rsync -av --delete --exclude '.git' ./ /var/www/hamster.skin/public/
```

В конфигурации Nginx необходимо указать:

```nginx
server_name hamster.skin www.hamster.skin;
root /var/www/hamster.skin/public;
index index.html;
```

Настройка DNS и HTTPS выполняется на VPS отдельно. GitHub Pages и CNAME-файл для этого проекта не нужны.

## Структура

- `index.html` — вся страница и семантические блоки;
- `styles.css` — адаптивное оформление и анимации;
- `script.js` — локальный тест с четырьмя вопросами;
- `assets/` — векторные иллюстрации, favicon и social preview;
- `robots.txt`, `sitemap.xml` — базовая индексация.

Все биржевые «котировки» на сайте вымышлены. Материалы носят исключительно развлекательный характер, не являются финансовыми рекомендациями.
